## System Design Components

A collection of hands-on mini-projects designed to practice and implement core software architecture and System Design components in code.

### Overview

The primary goal of this repository is to move beyond pure theory and build isolated, functional scenarios where each mini-project explores a specific engineering challenge or architectural pattern.

---

### Key Objectives

* **Practical Implementation:** Write real code to understand the trade-offs, concurrency models, and failure modes of distributed systems.
* **Context Isolation:** Each project focuses independently on a single architectural component or infrastructure service.
* **Industry Tooling:** Explore standard technologies applied to real-world backend scenarios, such as message brokers, in-memory caches, and consensus patterns.

---

### Key Components Addressed

* **Asynchronous Messaging:** Decoupling services and handling heavy workloads using message queues (e.g., RabbitMQ).
* **Distributed Concurrency Control:** Preventing race conditions and ensuring mutual exclusion using distributed locks (e.g., Redis).
* **Traffic Management:** Implementing Rate Limiters, API Gateways, and load-shedding strategies.
* **Data Engineering & Indexing:** Exploring underlying storage mechanics, such as LSM-tree storage structures and memory tables.
